# Meio Spike Check

## 1.1.1

- Report window: click a column header to sort by it (click again to reverse); your choice
  is kept
- Memory column wider, so large growth isn't cut off

## 1.1.0

- `/spikes` opens a report window: the worst addons first, their worst frame and memory growth
- Turn off an addon for the next reload from the report, to test if the stutter goes (Turn on
  puts it back); Reload now button
- The report from before your last reload stays in the window until you start again
- Button to turn on the game's addon profiler
- Settings panel (Esc > Options > AddOns): print each frame in chat, threshold
- The chat report moved to `/spikes report`

## 1.0.0

- First release: `/spikes start`, play, then `/spikes` shows which addons had the most long
  frames; each frame over 100 ms is printed in chat as it happens
